Route conventions

  • Draw points along the roads, from the first pickup area towards school.
  • The server asks OSRM for a real road route — no straight lines.
  • Routes are stored so they end near the school. If drawn backwards, saving automatically reverses them.
  • Stops snap to the route and are ordered by road distance.
  • Morning trips run towards the school; afternoon trips run in the opposite direction.

Public OSRM is a free service. You are only making a request when you preview or save a route.
